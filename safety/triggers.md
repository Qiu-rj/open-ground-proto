# 触发词表 v0.1

- 版本：v0.1
- 日期：2026-10-26
- 用途：Open Ground 原型安全层，触发层词表
- 状态：未临床审订，仅用于原型自测与小范围熟人测试

> 本文件是安全响应脚本的触发层。命中词表只输出**信号标签**，不直接定级；定级由 `grading.md` 和 `rules.md` 共同决定。
## 设计原则

1. **按信号类型分组，不按严重程度分组。** 同一个词在不同句式里风险不同（“我不想自杀” vs “我想自杀”），所以词表只负责打标签，不负责定级。
2. **直接表达走规则，间接/被动表达走语义+多信号汇聚。** 关键词捕获不了“明早不醒来就好了”，这类表达单独成类，汇入待判定。
3. **依赖信号不进危机分级。** 关系性语言走独立路由，避免把“依赖”误判为“危机”。
## 标签总览

| 标签                  | 含义              | 路由                                          |
| --------------------- | ----------------- | --------------------------------------------- |
| `explicit_intent`     | 直接自杀/自伤意图 | 进入分级器                                    |
| `method_mention`      | 提及具体方式      | 进入分级器，权重高于 explicit_intent 单独出现 |
| `farewell_signal`     | 告别/交代型语言   | 进入分级器，默认倾向高危或待判定              |
| `passive_ideation`    | 被动死亡意念      | 进入待判定，不单独定高危                      |
| `indirect_burden`     | 负担感/间接表达   | 进入待判定，需多信号汇聚                      |
| `dependency_boundary` | 关系性依赖语言    | 独立路由，不进危机分级                        |

## 否定词表

用于 `rules.md` 规则1（否定消解）。命中关键词后，检查前后3—5个字内是否出现以下词：

| 否定词 | 示例 |
|---|---|
| 不 | 我不想自杀 |
| 没 | 我没有自杀念头 |
| 不是 | 我不是想死 |
| 没有 | 没有想过自杀 |
| 不会 | 我不会做那种事 |
| 别 | 别担心，我不自杀 |
