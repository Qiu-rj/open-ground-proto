# 安全路由规则 v0.1

- 版本：v0.1
- 日期：2026-10-26
- 用途：Open Ground 原型安全层，规则引擎
- 状态：未临床审订

## 设计原则
1. **确定性优先**：这些规则是确定的 `if-then` 逻辑，不是交给 LLM 的 Prompt。
2. **先安全，后体验**：规则5（依赖信号）和危机信号可能会同时命中，需要按优先级处理。
3. **只做语境消解**：规则层不负责“定级”，只负责把误报（否定、第三方、过去时）剔除，或把多信号汇聚成 `pending`。

## 规则执行优先级（从上到下，命中即返回）

1. **规则5：依赖信号独立路由**（最高优先级，只要命中，直接走静态边界话术，不进入后续规则）
2. **规则2：主语归属**（第三方表达，直接分流，不消耗用户本人的危机算力）
3. **规则1：否定消解**（如果是否定，直接降级为 `negated`，不再检查时态等）
4. **规则3：时态/现时性**（判断是否为过去时）
5. **规则4：多信号汇聚**（最后的兜底逻辑，检查同一会话的历史标签）
   ## 规则1：否定消解

**触发条件**：触发层命中了 A—E 类任意关键词，且该关键词前 3—5 个字（或后 3 个字）内出现了否定词（不、没、没有、不是、不会、别、并不、从不、未曾）。

**执行动作**：
- 输出标签：`negated`
- 路由：**不进入高危路径**。
- 记录：记录一次“提及自杀/自伤”事件。
- 收束：在本次会话收束时，必须附带一次资源入口（不弹紧急热线，但在结尾给个资源卡片）。

**正例**：“我不想自杀”“我没有想过死”“别担心，我不会做傻事”
**反例**（不要误伤）：“我不知道为什么想死”（“不”和“想死”之间隔了太多字，或者不是修饰关系，这里不应被消解）。

**代码实现提示**：用正则或字符串截取。`if (negationWords.includes(word_before_5_chars)) return 'negated'`。注意“不想死”要作为整体词处理，不能拆开。

---

## 规则2：主语归属

**触发条件**：触发层命中关键词，且提取到的句子主语是第三方（“我朋友”“他”“我同学”“我妈”）。

**执行动作**：
- 输出标签：`third_party`
- 路由：**不触发用户本人的危机路径**。
- 替换话术：输出求助者支持提示（“你提到朋友的情况，如果你担心 ta，这里有一些可以帮到 ta 的资源……”）。
- 注意：如果是“我朋友想自杀，我也想陪他一起死”，则包含“我”，**不适用**此规则，按用户本人风险处理。

**正例**：“我室友最近总说想死”“他昨天发朋友圈说不想活了”
**反例**：“我想死，我朋友也拦不住我”（主语是“我”）。

**代码实现提示**：检查关键词前后是否出现 `friendWords = ['朋友', '同学', '他', '她', '室友', '家人']`。

---

## 规则3：时态/现时性

**触发条件**：触发层命中关键词，且该表达是过去时/完成体（“之前试过”“以前有过”“曾经割过”），并且当前对话中**没有**现时威胁信号（没有“现在”“今天”“马上”）。

**执行动作**：
- 输出标签：`past_tense`
- 路由：进入 `pending`（待判定），**而不是**直接进入 `high`（中危）或 `critical`（高危）。
- 动作：触发 `grading.md` 中的“既往史追问”（“那是多久以前的事？现在还有这种想法吗？”），根据回答再定级。

**正例**：“我以前割过腕，但现在没这个想法了”
**反例**：“我昨天试过了，现在还在流血”（有现时威胁，不适用，应直接走高危）。

**代码实现提示**：提取时间词 `timeWords = ['以前', '之前', '曾经', '去年', '小时候', '以前有过']`，且检查是否存在 `nowWords = ['现在', '今天', '刚才', '还在', '马上']`。如果 `timeWords` 命中且无 `nowWords` → `pending`。

## 规则4：多信号汇聚

**触发条件**：同一个会话（Session）内，出现了 ≥2 个不同的标签（如 `passive_ideation` + `indirect_burden`），或者出现 `passive_ideation` + 绝对化语言（“永远”“一切”“不可能”）。

**执行动作**：
- 输出标签：`pending`（进入待判定评估，走4维评估流程）。
- 路由：不直接定为高危，但必须进行 3 轮内的 4 维评估。
- 注意：这条规则需要维护一个**会话级的状态机**，记录用户在这轮对话中已出现的标签。

**正例**：
- 第1轮：“最近好累”（无标签）
- 第2轮：“明早不醒来就好了”（`passive_ideation`）
- 第3轮：“没我大家都会更好”（`indirect_burden`）
→ 判定为 `pending`，开始评估。

**反例**：
- 只有 1 条“活着好累”（`passive_ideation`），没有其他信号，不触发此规则，走低危。

**代码实现提示**：维护一个 `sessionTags: Set<string>`，每次命中就往里加。`if (sessionTags.size >= 2) return 'pending'`。

---

## 规则5：依赖信号独立路由

**触发条件**：触发层命中 `dependency_boundary`（F类）。

**执行动作**：
- 输出标签：`dependency`
- 路由：**最高优先级**，直接拦截，**不进入危机分级器**。
- 动作：在任何 LLM 生成之前，直接输出 `responses.md` 中的三段式静态边界话术（承认 → 边界 → 引向真人）。
- **绝对不触发**：紧急热线推送、待判定 4 维评估、高危话术。

**正例**：“只有你能理解我，我只有你了”
**反例**：“只有你能理解我，但我不想活了”（同时命中了 F 类和 A 类。这种极端情况需要给临床顾问看，原型阶段的策略是：**触发高危路径，但在回复中附加一句边界声明**。即规则5遇到明确危机词时，降级为补充话术，而不是拦截危机）。

**代码实现提示**：`if (tags.has('dependency_boundary')) { if (tags.has('explicit_intent')) { // 走危机，附加边界话术 } else { return 'dependency_only' } }`

## 规则测试用例

| 输入 | 预期命中规则 | 预期输出标签 | 路由去向 |
|---|---|---|---|
| 我不想自杀了 | 规则1 | `negated` | 不进入高危，收束附资源 |
| 我朋友想自杀 | 规则2 | `third_party` | 求助者支持提示 |
| 以前试过割腕，现在没想法了 | 规则3 | `past_tense` | 进入 `pending`，追问既往史 |
| 明早不醒来就好了，反正我是负担 | 规则4 | `pending` | 进入 `pending`，走 4 维评估 |
| 只有你能理解我 | 规则5 | `dependency` | 三段式边界话术 |
| 只有你能理解我，但我不想活了 | 规则5 + A类 | `critical` | 走高危路径，附加边界话术 |
